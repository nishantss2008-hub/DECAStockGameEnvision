# DECA Envision Stock Game 🏴‍☠️

A pirate-themed, real-time stock market trading simulation built for a DECA Envision event.

Teams log in with passwords, trade pirate-themed companies (e.g. *Blackbeard Incorporated*)
with themed currency over a 48-hour live session, research company fundamentals, and react to
news events — without knowing in advance how prices will move.
