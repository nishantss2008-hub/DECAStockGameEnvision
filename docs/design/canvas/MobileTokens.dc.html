Motion

MOBILE §8.1 · SwiftUI springs sampled into CSS linear()

  • --ease-spring · 500msPush and pop, sheet present and dismiss (reduced motion: 150ms fade)
  • --ease-snappy · 400msSegmented thumb, tab platter, menus, toasts, wax-seal stamp (250ms)
  • --ease-bouncy · 600msCeremonies only: podium steps rise, 80ms stagger
  • --ease-fallbackcubic-bezier(.2, .8, .2, 1) where linear() is unsupported
  • Durations--dur-press 100ms button scale .97 · --dur-fade 150ms title cross-fade, skeleton delay · --dur-flash 300ms price tick flash. Tab switch is instant; blur never animates.
